# Diyse — Campaign Playtest Matrix

**Status:** ACTIVE CAMPAIGN PLAYTEST FRAMEWORK  
**Balance/QA authority:** `../README.md`

Run at minimum these route profiles:

| Route | Optional behavior |
|---|---|
| Campaign-only | minimal optional content |
| Light optional | a few quests/Hunts |
| Typical developed | regular optional play |
| Heavy optional | most available optional content |
| Completionist | broad completion before the final cutoff |

Exact route-ending Player Levels are rebuild-pending and must be measured rather than assumed.

## Record per chapter / major checkpoint

- start/end Player Level;
- active party / available roster;
- equipment tier/loadout;
- selected classes / Class Levels;
- CEXP by character;
- Standard Card / Prime loadouts;
- **G**;
- consumable stock;
- ordinary battles fought;
- flees;
- wipes;
- temporary KOs;
- boss turns/rounds;
- ending HP/MP;
- item/recovery use;
- optional content completed;
- elapsed playtime.

## Mandatory checks

- Chapter 0 grants no Player Levels;
- no Subclass access before **Sixfold Volition**;
- active combat party cap remains 4;
- Player Level cap remains 70;
- optional progression creates a measurable advantage without dynamic enemy scaling;
- full Base + Subclass completion under normal developed play lands around the **Lv55–60 target window** after the CEXP rebuild;
- exact chapter/endgame level centers are not frozen until the progression rebuild closes them.

## CEXP special note

Record exact Base + Subclass completion levels per character on mandatory, typical, heavy-optional, and completionist routes. Those measurements are inputs to the queued CEXP recalibration, not predetermined results.
