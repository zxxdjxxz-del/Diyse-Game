## Current rule

Current Prime availability rule:
- each Prime identity has **one use until restored by valid rest or an explicit authored restoration effect**;
- spent/Ready state persists across battle end until valid restoration;
- same-bar state changes do not refresh Prime availability;
- genuine fresh-HP boss forms also **do not refresh Prime availability**;
- form changes do not create a new automatic Prime-use allowance;
- after a Prime dismissal, **3 full normal party rounds** must complete before another Ready Prime may be invoked.
- Prime invocation and Prime commands cost **0 MP**.

Therefore:

> **Crownless Siege Marshal → Crownless War Engine does not refresh spent Prime identities when the fresh War Engine body begins.**

The existing Chapter-7 / Major-Hunt-#2 two-body architecture remains separate from Prime availability. This file no longer authorizes a form-transition Prime refresh.
