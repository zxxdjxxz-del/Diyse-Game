# Diyse — Music Originality & Reference Rule

**Status:** ACTIVE ORIGINALITY / REFERENCE RULE  
**Parent authority:** `../AUDIO_AUTHORITY_MASTER.md`

Real-world music may be used for:
- study;
- vocabulary;
- arrangement analysis;
- production analysis;
- instrument research;
- mix-reference discussion;
- high-level influence coding.

Final Diyse music must be original.

Do not copy:
- protected melodies;
- lyrics;
- recognizable riffs;
- distinctive samples;
- song-specific formal sequences;
- identifiable signature arrangements.

## Research wording
A reference artist/album in an archive file means:
> "study this musical/production behavior"

not:
> "make a Diyse track that sounds like this exact song."

## Sample-source licensing
Any literal sample/instrument source used in production must have:
- verified licensing;
- provenance;
- redistribution/deployment compatibility;
- Android/runtime suitability.

Research-source availability does not automatically authorize shipping it.
