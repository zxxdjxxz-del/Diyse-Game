# Diyse — Hit / Miss / Evade Route

**Status:** ROUTING SURFACE  
**Authority:** `BATTLE_SYSTEM_MASTER.md` §9

A legal valid action hits by default.

Miss or Evade occurs only when an explicitly authored current effect creates it. Sure Hit may override an eligible Evade effect when that owning effect permits it.

This file defines no additional universal hit-resolution stat or formula.
