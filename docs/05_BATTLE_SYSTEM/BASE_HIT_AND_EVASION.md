# Diyse — Hit / Miss / Evade Route

**Status:** ROUTING SURFACE  
**Authority:** `BATTLE_SYSTEM_MASTER.md` §9

There is no universal Accuracy-vs-Evasion roll and no permanent Accuracy or Evasion core stat.

A legal valid action hits by default. Miss/Evade exists only where an explicit authored effect creates it. Sure Hit may override an eligible Evade effect when that owning effect permits it.

Do not restore a parallel Base Hit formula here.
