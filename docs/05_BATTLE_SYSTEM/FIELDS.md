# Diyse — Field / Global Effect Boundary

**Status:** PARKED CONTENT BOUNDARY  
**Authority:** `BATTLE_SYSTEM_MASTER.md`

The current battle system does not define a separate universal Field lifecycle or priority phase.

An Ability, Card, item, enemy, or encounter may author a field/global effect only when that effect explicitly defines its own timing, targets, duration, and interactions through the current TURN / EXECUTION framework.

Exact Card/class Field content remains part of the corresponding content rebuild.
