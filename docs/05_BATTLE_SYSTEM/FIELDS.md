# Diyse — Field Effect Boundary

**Status:** PARKED CONTENT BOUNDARY  
**Authority:** `BATTLE_SYSTEM_MASTER.md`

The consolidated TURN / EXECUTION redesign does **not** currently define a separate universal Field lifecycle, round clock, or Field priority phase.

An Ability, Card, item, enemy, or encounter may still author a field/global effect, but that effect must state its own current timing, targets, duration, and interaction rules using the battle master rather than inheriting the former round-based Field framework.

Exact Card/class Field content is part of the parked content redesign. Do not use this file to restore a parallel round-duration or initiative system.
