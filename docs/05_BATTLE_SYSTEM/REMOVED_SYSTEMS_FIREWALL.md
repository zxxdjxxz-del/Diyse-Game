# Diyse — Removed Combat Systems Firewall

**Status:** ACTIVE COMBAT RETIREMENT FIREWALL  
**Authority:** current battle-system owner plus later explicit approved corrections.  


The following systems are removed from current global combat design and must not return under renamed equivalents:

- **Barrier**
- **Brace**
- global **Break/Stagger meter**
- Break buildup/contribution/resistance/threshold systems
- Card Seals
- global Rune-effect system
- Imprints
- natural `Accuracy` stat

## Still valid

Do not confuse removed systems with valid current concepts:
- **Guard** remains valid;
- **Staggered** remains a harmful status;
- **Base Hit** remains the action-side hit value;
- **Evasion** remains a target-side property;
- ordinary stat Up/Down effects remain valid;
- Fields may exist where explicitly authored;
- Prepared/setup effects may exist where explicitly authored;
- protected/scripted encounter states may exist where explicitly authored.

## Migration rule

Historical tracker text containing a removed system belongs in Git history and must not be copied back into active canonical domain files.
