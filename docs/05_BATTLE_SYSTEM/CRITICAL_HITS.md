# Diyse — Critical Hit Route

**Status:** ROUTING SURFACE  
**Authority:** `BATTLE_SYSTEM_MASTER.md` §9

Current universal critical baseline:

- base chance: **5%**
- damage multiplier: **×1.5**
- no permanent Critical Chance core stat
- Attack can crit by default
- Abilities and Cards define crit eligibility explicitly
- healing does not crit by default
- crit has no automatic timeline effect

Do not define a parallel critical formula here.
