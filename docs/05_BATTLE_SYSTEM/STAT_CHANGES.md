# Diyse — Temporary Stat Change Route

**Status:** ROUTING SURFACE  
**Authority:** `BATTLE_SYSTEM_MASTER.md` §11

Current generic temporary stat changes exist only for:

- Strength
- Magic
- Intelligence
- Defense
- Spirit

Global baseline:

- **Up:** +25%
- **Down:** −25%
- **Duration:** 4 affected TURNs
- same-state reapplication refreshes rather than stacking magnitude
- opposing Up/Down cancels the existing state to neutral

There is no generic Speed Up/Down; **Quick / Slow** own TURN-frequency modification.

Do not define separate Minor/Standard/Major global stat tiers here.
