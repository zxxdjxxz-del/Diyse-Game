# 05_BATTLE_SYSTEM

Canonical global battle-system domain.

## Authority

`BATTLE_SYSTEM_MASTER.md` is the **single current global battle-system authority**.

Supporting files in this folder are routing/index surfaces only. They must not define parallel combat formulas, round systems, status rules, targeting rules, or Prime sequencing.

## Current supporting routes

- `TURN_AND_ROUND_RULES.md` → TURN / EXECUTION timeline and timing
- `TARGETING_AND_RETARGETING.md` → targeting and automatic retargeting
- `DAMAGE_FORMULAS.md` → damage/healing/potency resolution
- `BASE_HIT_AND_EVASION.md` → current hit/miss/evade boundary
- `APPLICATION_RELIABILITY.md` → status application/susceptibility boundary
- `CRITICAL_HITS.md` → critical-hit rules
- `ELEMENTS.md` → four-element affinity rules
- `STATUS_EFFECTS.md` → current status set
- `STAT_CHANGES.md` → temporary stat Up/Down rules
- `FIELDS.md` → field-effect boundary pending content redesign
- `GUARD.md` → Defend/Ward defensive routing
- `BOSS_FORM_RULES.md` → boss-form interaction routing
- `PRIME_ROUND_SEQUENCING.md` → parked Prime sequencing boundary

Cross-domain content remains owned by its numbered domain:
- character Ability/passive content → `06_CLASSES_AND_ABILITIES`
- Card/Prime identities and content → `07_CARDS`
- item/equipment catalogs → `08_ITEMS_AND_EQUIPMENT`
- enemy/encounter content → `09_ENEMIES_AND_ENCOUNTERS`
- progression/EXP/CEXP → `10_PROGRESSION_AND_EXP`

Git history is recovery infrastructure, not current battle authority.
