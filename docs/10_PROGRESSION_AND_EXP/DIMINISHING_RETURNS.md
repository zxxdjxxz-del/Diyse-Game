# Diyse — Weak-Enemy Player-EXP Diminishing Returns
**Historical migration provenance:** v85-era consolidated tracker.
**Historical progression provenance:** Audit123–Audit128 plus compatible later raw-stat audits.
**Authority treatment:** this repository file is current progression-domain authority; Audit/v85 references remain provenance only. Numeric reward/budget tables remain provisional where marked pending the planned progression rebuild.
**Current structural rule:** Mastery Points do not exist; Masteries unlock automatically from Class Level under current repository class/progression authority.


Applies only to repeatable/ordinary enemy-kill **Player EXP**.

Reference Level:
> **highest current Level among the permanent party**

Let `D = Party Reference Level − Enemy Level`.

| D | EXP received |
|---:|---:|
| ≤0 | 100% |
| 1–2 | 90% |
| 3–4 | 65% |
| 5–6 | 40% |
| 7–9 | 20% |
| 10–14 | 10% |
| 15+ | 5% |

Round to nearest whole EXP, minimum **1**.

There is no bonus above 100% for stronger enemies.

Exempt:
- Side Quest completion packages;
- Character Quest completion packages;
- Regional Hunt authored packages;
- Major Hunt authored packages;
- mandatory one-time named/story/boss awards.

Principle:
> **WEAK ENEMIES DIMINISH — AUTHORED CONTENT DOES NOT**

Do not apply this table to CEXP.
