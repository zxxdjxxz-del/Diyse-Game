# Diyse — Class EXP (CEXP)

**Status:** ACTIVE STRUCTURAL AUTHORITY / EXACT THRESHOLDS OPEN

## Class-Level structure

- Base Class cap: **CL13**
- Subclass cap: **CL13**
- Base and Subclass CEXP are separate.
- CEXP goes to the character's currently selected class unless an explicit later rule changes that behavior.
- Active/reserve participation does not by itself change the character's CEXP entitlement.
- CEXP does not automatically split between class lines.

Exact cumulative CEXP thresholds for CL1–CL13 are open for the progression rebuild.

No previous numeric CEXP curve is current authority.
