# Diyse — Class EXP (CEXP)
**Current structural rule:** Mastery Points do not exist; Masteries unlock automatically from Class Level under current repository class/progression authority.


Both Base and Subclass use:
> **CL1 → CL13 / 0 → 6,000 CEXP**

| Class Level | Cumulative CEXP | CEXP to next |
|---:|---:|---:|
| CL1 | 0 | 150 |
| CL2 | 150 | 200 |
| CL3 | 350 | 250 |
| CL4 | 600 | 350 |
| CL5 | 950 | 400 |
| CL6 | 1,350 | 450 |
| CL7 | 1,800 | 500 |
| CL8 | 2,300 | 550 |
| CL9 | 2,850 | 600 |
| CL10 | 3,450 | 700 |
| CL11 | 4,150 | 800 |
| CL12 | 4,950 | 1,050 |
| CL13 | 6,000 | — |

## Assignment
- every recruited permanent character earns the full CEXP package;
- active/reserve does not reduce CEXP;
- CEXP goes only to that character's **selected class**;
- unselected class receives 0;
- no automatic split.

If selected class is CL13, additional CEXP is lost.
It does not spill or convert into another resource.

There is **no current CEXP diminishing-return system**.
