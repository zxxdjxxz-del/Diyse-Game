# Diyse — Class Completion Timing

**Status:** ACTIVE TARGET / NUMERIC REBUILD PENDING

Exact per-character CEXP deficits, completion levels, optional acceleration amounts, and chapter checkpoints remain open until the campaign CEXP rebuild is certified.
