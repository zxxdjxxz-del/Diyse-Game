# Diyse — Progression Master

**Current structural rule:** Mastery Points do not exist; Masteries unlock automatically from Class Level.

## Player Level

Player EXP controls character Level and natural stat growth.

Cap:
> **Lv70**

## Class Level

CEXP controls the selected class:
> **Battle → CEXP → selected Class Level → Ability / Trait / Mastery unlock**

Both Base and Subclass use CL1–CL13.

## Chapter 0

Player Level is static. No character levels are gained.

## Sixfold Volition

Subclasses unlock at the end of Chapter 7.
No permanent character uses a Subclass before Volition.

## Provisional endgame relationship

Target for correctly managed mandatory-route full Base + Subclass completion:
> **Player Lv55–60**

Current planning values:
- the Player-Level spine is a reference baseline pending rebuild;
- CL13 currently uses **6,000 cumulative CEXP** as the reference threshold;
- post-Volition mandatory CEXP is currently modeled as **7,000 by end Ch12** and **8,500 by Last Shelter**;
- optional CEXP totals are owned by `OPTIONAL_CEXP.md` and remain provisional;
- Last Shelter is currently modeled near ~Lv60;
- normal ending is currently modeled near ~Lv62;
- player cap remains structurally **Lv70**.

These EXP/CEXP totals and derived completion points are **not final balance locks**. The planned progression rebuild must recertify them against current chapter structure, Major-Hunt timing, and mandatory/completionist baselines.
