# Diyse — Animation & Production Cost Rules

**Status:** ACTIVE VISUAL-PRODUCTION GUIDANCE  
**Authority:** current visual owner domains plus later explicit approved corrections.  
**Visual rule:** exact current visual masters control character/location identity; animation and production-cost decisions may simplify presentation but must not redesign that identity.


Prefer reusable:
- idle;
- walk/run;
- ready;
- strike;
- cast;
- hurt;
- KO;
- interact;
- item;
- Defend;
- weapon-family bases;
- class-family casting/attack overlays.

Named actions can combine:
- base motion;
- weapon pose;
- VFX;
- camera;
- hit reaction;
- short cut-in.

## Do not require by default
- full bespoke mocap-like animation for each Ability;
- cloth simulation;
- hair physics simulation;
- chain physics;
- destructible environment;
- crowd simulation;
- custom boss arena for every formation.

## Bosses
Spend new body/forms only when current encounter canon has:
- genuine fresh form;
- meaningful new silhouette/body;
- story importance sufficient to justify it.

Same-bar phase changes should usually use:
- state overlays;
- damage states;
- modular attachments;
- posture/animation changes;
- lighting/VFX changes.

Do not manufacture a new body merely because HP crossed a threshold.
