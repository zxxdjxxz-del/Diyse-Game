**Current written authority:** **v2.20 / Audit135** plus newer explicit visual approvals/corrections already accepted in the project conversation.

**Visual rule:** the newest explicitly approved visual reference for a character/location controls all derivative field sprites, battle sprites, portraits, cut-ins, model sheets, and promotional derivatives unless that exact visual is later revised.


Prefer reusable:
- idle;
- walk/run;
- ready;
- strike;
- cast;
- hurt;
- KO;
- interact;
- item;
- Defend;
- weapon-family bases;
- class-family casting/attack overlays.

Named actions can combine:
- base motion;
- weapon pose;
- VFX;
- camera;
- hit reaction;
- short cut-in.

## Do not require by default
- full bespoke mocap-like animation for each Ability;
- cloth simulation;
- hair physics simulation;
- chain physics;
- destructible environment;
- crowd simulation;
- custom boss arena for every formation.

## Bosses
Spend new body/forms only when current encounter canon has:
- genuine fresh form;
- meaningful new silhouette/body;
- story importance sufficient to justify it.

Same-bar phase changes should usually use:
- state overlays;
- damage states;
- modular attachments;
- posture/animation changes;
- lighting/VFX changes.

Do not manufacture a new body merely because HP crossed a threshold.
