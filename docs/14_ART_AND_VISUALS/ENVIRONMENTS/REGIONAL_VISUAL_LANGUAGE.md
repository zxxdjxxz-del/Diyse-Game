# Diyse — Regional Visual Language

**Status:** ACTIVE VISUAL AUTHORITY  
**Shared rendering authority:** `../DIYSE_VISUAL_STYLE_CANON.md`  
**Top-level visual routing:** `../ART_VISUAL_MASTER.md`

## Yahtrenhold
Core read:
- historic royal/civic Yahtrean center;
- Caelora;
- established roads/institutions;
- forested/settled core geography where appropriate.

Crest visual language:
- green/gold modern Yahtrean institutional/royal symbolism.

## The Westways
Core read:
- road country;
- forests;
- frontier settlements;
- route infrastructure;
- western military approaches;
- colder/more severe terrain toward northern/frontier sites.

## The Greyspires
Core read:
- grey/snowy mountain terrain;
- high relief;
- cold-weather settlement/forge infrastructure;
- visually distinct from the blacker Blackspine.

## Black Host Territory
Core read:
- land, not water;
- dark jagged outcroppings;
- sparse trees;
- rivers;
- mixed harsh ground;
- authoritarian military/imperial infrastructure.

Do not convert the whole territory into a featureless black wasteland.

## The Blackspine
Visually:
- darker mountain frontier mass;
- materially distinct from Greyspires.

The final master map intentionally does not print its name.
