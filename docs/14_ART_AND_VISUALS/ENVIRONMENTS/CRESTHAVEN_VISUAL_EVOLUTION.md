## Identity
Cresthaven is:
- an abandoned Crown fort/outpost;
- in forest;
- smaller than a city;
- reactivated as party headquarters in Chapter 3.

It is not:
- a giant capital;
- a gleaming new fortress from first arrival;
- part of the Old City/Suppressed Archives.

## Production strategy
Build one evolving master environment.

Suggested state progression:
1. abandoned / recently reopened;
2. survey/records/medical/security activity;
3. functional party headquarters;
4. later service/project expansion;
5. late-war/final-operation readiness.

State change should be sold through:
- occupied rooms;
- banners/signage;
- worktables;
- crates;
- lighting;
- repaired access;
- NPC clusters;
- project stations.

Do not create a wholly new map for every chapter-state.
