## Civilization-level identity
Ancient Diysean architecture must feel:
- human-built;
- technically sophisticated;
- magical-engineering driven;
- civilization-scale;
- old enough that survival is uneven.

## Surviving materials
Prefer believable survival:
- heavy stone;
- foundations;
- masonry;
- large protected structures;
- durable metal/ceramic/magical components.

Fine furnishings/records/exposed machinery may be:
- broken;
- partial;
- preserved only in protected contexts.

## Visual sublanguages
Compatible reusable subfamilies:
- cartographic / Wayfinder;
- archive;
- command / judicial;
- regulation / Reaction Annex;
- reactor / Crest;
- deep-city / Last Weapon infrastructure.

They should read as related parts of one civilization without making every facility identical.

## Modern knowledge firewall
Early scenes may show visual relationships the **player** can later recognize.

Characters must not react as if they already know:
- giant buried Crest;
- integrated Underground Crest civilization;
- Entity;
- Last Weapon truth.

Visual foreshadowing is allowed.
Character omniscience is not.
