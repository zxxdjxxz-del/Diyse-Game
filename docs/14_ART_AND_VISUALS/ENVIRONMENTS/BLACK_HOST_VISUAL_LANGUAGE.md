## Core identity
Authoritarian imperial military/industrial language:
- dark metal/stone;
- severe vertical/fortified geometry;
- red/crimson accents where established;
- functional military logistics;
- repeated state/command symbolism;
- controlled, engineered infrastructure.

## Variation
Black Host locations must not all be the same fortress.

Differentiate:
- frontier town;
- transfer bastion;
- forge/industrial occupation;
- medical/research installation;
- command position;
- imperial strongpoint;
- capital;
- Veiled Citadel.

## Humanity
Black Host Territory still contains:
- civilians;
- ordinary structures;
- roads;
- supply infrastructure;
- lived-in space.

Do not visually imply every citizen is a monstrous combatant.

## Ancient grafting
Late-war Black Host excavation areas may show:
- modern clamps;
- scaffolds;
- conduits;
- braces;
- cataloguing/industrial attachments

around much older Diysean infrastructure.

The visual must communicate:
> appropriation / attempted interface

not successful reconstruction of the ancient Last Weapon.
