# Diyse — Four-Element Visual Language

**Status:** ACTIVE ELEMENT VISUAL AUTHORITY  
**Shared rendering authority:** `../DIYSE_VISUAL_STYLE_CANON.md`  
**Combat authority:** `../../05_BATTLE_SYSTEM/`

Standard elements exactly:
- Fire
- Ice
- Lightning
- Earth

## Linked harmful-status language
Where authored:
- Fire → Burn
- Ice → Freeze
- Lightning → Stun
- Earth → Staggered

## Production requirement
Each element should have a distinct readable:
- motion language;
- impact language;
- particle/shape family;
- sound handoff;
- icon/color treatment;

without requiring every spell to be visually unique.

## Environmental phenomena
Rain, wind, rivers, spray, mist, and condensation remain ordinary environmental visuals and do not add combat elements.

## Ruin
Ruin is:
- special affinity/school;
- not a fifth standard element.

Do not place Ruin in a five-element wheel.
