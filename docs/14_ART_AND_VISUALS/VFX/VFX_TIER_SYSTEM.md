## VFX tiers
- **V1 — Common**
- **V2 — Face / class identity**
- **V3 — Named signature**
- **V4 — Prime / boss spectacle**

V4 is not a synonym for "important move."
Reserve it for true top-tier visual events.

## Reuse principle
A named action does not require a completely bespoke animation body rig.

Prefer:
- shared base motion;
- class/Face overlays;
- named signature insert;
- reusable impact language;
- selective camera change.

## Android
Decorative intensity may scale down.
