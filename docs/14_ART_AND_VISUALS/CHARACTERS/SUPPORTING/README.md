# Supporting Character Visual Navigation

This folder is a compatibility/navigation layer. For the supporting characters that currently have exact repository masters:

- Maevra → `../../PRODUCTION/CHARACTERS/MAEVRA_CURRENT_VISUAL_LOCK.md` → `asset_sources/characters/current/maevra.jpg`
- Kessara → `../../PRODUCTION/CHARACTERS/KESSARA_CURRENT_VISUAL_LOCK.md` → `asset_sources/characters/current/kessara.png`

The first-name Maevra/Kessara files in this folder are redirects only. Their canonical surnames **Solmar** and **Durnan** remain current under `01_CHARACTERS`; deleted migration files must not override current visual or naming authority.

`ROYAL_AND_SUPPORTING_VISUALS.md` continues to cover other supporting characters that do not yet belong to the current eight-image repository-master set.
