# Supporting Character Visual Navigation

This folder is a compatibility/navigation layer inherited from the older visual-document organization. Folder placement does not itself establish or revise a character's current story role.

For current repository masters routed through this folder:

- Maevra → `../../PRODUCTION/CHARACTERS/MAEVRA_CURRENT_VISUAL_LOCK.md` → `asset_sources/characters/current/maevra.jpg`
- Kessara → `../../PRODUCTION/CHARACTERS/KESSARA_CURRENT_VISUAL_LOCK.md` → `asset_sources/characters/current/kessara.png`

Maevra is supporting/recurring allied command. Kessara has a current authoritative visual master, but this folder and its navigation files do **not** assert a story role for her. Neither is part of the permanent six-character party.

The first-name Maevra/Kessara files in this folder are redirects only. Deleted surname-bearing migration files are superseded and must not be reconstructed.

`ROYAL_AND_SUPPORTING_VISUALS.md` continues to cover other established supporting characters that do not yet belong to the current eight-image repository-master set. Do not apply the Maevra/Kessara no-surname correction to unrelated established supporting names unless explicitly revised.
