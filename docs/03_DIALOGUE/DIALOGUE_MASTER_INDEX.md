## Dialogue Engine rule
The Diyse Dialogue Engine is the production authoring method for current spoken dialogue across the game. It combines current story authority, character brains, relationship state, lived-world/economy context, map/traversal state, gameplay pressure, naturalistic/cinematic/comedic craft, anime expressiveness, and economical HD-2D staging.

A scene that has been generated through that process and then explicitly approved/locked by the user becomes current exact dialogue authority. **Approved Dialogue Engine output is not required to be regenerated again merely because it was generated by an earlier iteration of the same engine.**

Historical pre-Dialogue-Engine line-complete material remains reference/provenance unless separately promoted or explicitly line-locked.
