## Current difficulty hierarchy

> **baseline ordinary enemy < strong normal-pool enemy < mandatory story boss < Regional Hunt < Major Hunt**

There is no separate Elite encounter category.

## Combat rebuild boundary

Enemy identities, ecology, placements, mandatory/optional role, and form/body architecture remain authoritative where their current owner says so.

Exact enemy:
- combat stats;
- action kits;
- Potencies;
- status riders;
- Execution/Return;
- Delay/Interrupt classification;
- numerical difficulty

must be rebuilt or explicitly recertified under the current battle system before being treated as final implementation data.

Leaf files should preserve current identity/placement/form information without carrying an incompatible combat model forward.
