# Capture floor

While:
> **either Retreat Beacon remains functional**

Varkesh has an authored capture floor at:
> **20% Max HP = 3,421 HP**

If incoming damage would reduce Varkesh below 3,421 HP:
- final HP clamps at 3,421;
- the damaging action otherwise resolves normally;
- battle continues;
- Varkesh does not automatically escape;
- the player must eliminate the remaining Retreat Beacon(s).

When both Retreat Beacons are destroyed:
> the 3,421-HP capture floor is removed permanently.

Then Varkesh can be reduced to 0 HP.

At 0 HP with both Beacons destroyed:
- Varkesh's unresolved selected action is canceled;
- combat ends immediately;
- S068 capture sequence begins;
- Varkesh is **captured alive**.

Prime damage obeys the same floor while a Beacon remains.

This is not a universal human-enemy HP-floor rule.
