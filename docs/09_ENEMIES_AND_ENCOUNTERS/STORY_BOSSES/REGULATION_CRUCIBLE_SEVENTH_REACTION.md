## Four elemental chambers

Exactly four:
- Fire
- Ice
- Lightning
- Earth

Each chamber:

| HP | DEF | Spirit | EVA | SR |
|---:|---:|---:|---:|---:|
| **300** | **48** | **50** | 0 | 10 |

Chambers:
- do not take independent turns;
- deal no direct damage themselves;
- are therefore **Power N/A**;
- are only targetable while active;
- remain destroyed once reduced to 0 HP;
- never respawn.

Their function is to determine:
1. which elements the core may currently use;
2. which elemental traits survive into Form II.

## Active-chamber rotation

Beginning-of-round rotation:
1. Fire / Ice
2. Lightning / Earth
3. Fire / Lightning
4. Ice / Earth
5. repeat

If a scheduled chamber was destroyed:
> its slot remains empty.

If both scheduled chambers were destroyed:
> that round is a core-only window.

- Physical / Neutral
- **185 Power**
- Base Hit **100**
- no harmful-status rider

### Pairwise Return
- one party member
- up to two Magical hits
- one hit for each currently active chamber

> one 100-Power hit.

> Pairwise Return is unavailable that round.

## Inherited element cycle

Form II cycles only among elemental chambers that survived Form I.

> Fire → Ice → Lightning → Earth

> the inherited cycle becomes **Colorless** and has no elemental harmful-status rider.
