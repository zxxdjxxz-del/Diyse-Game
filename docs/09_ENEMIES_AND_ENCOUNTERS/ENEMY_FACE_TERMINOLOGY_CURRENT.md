# Diyse — Enemy / Encounter Face Terminology

**Status:** ACTIVE CURRENT-FACING TERMINOLOGY HANDOFF  
**Face owner:** `../07_CARDS/SIX_FACES.md`

Current Six-Face names used by enemy/encounter fiction are exactly:
> **Might / Elements / Grace / Perception / Memory / Ruin**

Required encounter-facing replacements:
- `Acuity` Face → **Perception**
- `Change` Face → **Memory**
- older `Resource` Face → **Perception**

An enemy, support, state, protocol, room, record, or attack may use a Face name descriptively only where the owning encounter/story explicitly establishes that terminology.

Face-name usage by an enemy does **not** grant:
- Standard Card access;
- Prime access;
- player Card slots;
- Face-specific collectible ownership;
- a hidden player-style Card command.

The existing enemy Face-name firewall therefore remains intact under the new terminology.

Ordinary English uses of `change`, `memory`, `perception`, `resource`, or `acuity` remain valid where they are not the Six-Face labels.

Current encounter reward correction:
- Warden of the Nameless / Revision Arbiter grants **Split Moment — Memory**.

This handoff changes terminology only and does not alter enemy raw stats, Powers, action selection, statuses, encounter placement, or difficulty.
