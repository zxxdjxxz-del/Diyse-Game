# Diyse — Enemy / Encounter Face Terminology

**Status:** ACTIVE CURRENT-FACING TERMINOLOGY HANDOFF  
**Face owner:** `../07_CARDS/SIX_FACES.md`

Current Six-Face names are exactly:

> **Might / Elements / Grace / Perception / Memory / Ruin**

An enemy, support, state, protocol, room, record, or attack may use a Face name descriptively only where its owning story/encounter establishes that terminology.

Face-name usage by an enemy does not grant:

- Standard Card access;
- Prime access;
- player Card slots;
- collectible ownership;
- a hidden player-style Card command.

Enemy combat behavior remains owned by the current battle and encounter systems.
