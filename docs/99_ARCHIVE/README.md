# 99_ARCHIVE

Historical/provenance material only.

## Non-authority rule
Files here:
- explain where current decisions came from;
- preserve migration history;
- preserve retired terminology/system lineage;
- help recover lost detail.

They do **not** override:
- current numbered-domain files;
- `00_MASTER_CONTROL`;
- newer explicit corrections.

## Archived in this package
- original project-organization migration plan
- domain migration batch log
- historical authority/source manifest
- retired authority index

Large historical source files such as the v603 archive and old consolidated trackers are referenced rather than duplicated when their binaries are not part of this artifact.
