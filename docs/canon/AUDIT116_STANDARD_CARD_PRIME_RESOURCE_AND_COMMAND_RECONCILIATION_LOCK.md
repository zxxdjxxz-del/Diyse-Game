# 2. Audit115 global combat rules remain controlling

Audit116 does **not** reopen the following Audit115 rules:

- standard elements are exactly **Fire / Ice / Lightning / Earth**;
- linked elemental statuses are Fire→Burn, Ice→Freeze, Lightning→Stun, Earth→Staggered;
- universal harmful statuses are exactly **Burn / Freeze / Stun / Staggered / Bleed**;
- status riders are explicit, never automatic merely because an attack has an element/affinity;
- Ruin is a special affinity/school, not a fifth standard element;
- Card Seals, global Rune effects, Imprints, and the Break/Stagger meter are removed;
- stat Up/Down effects, Fields, Guard/Barrier, Prepared states, and other authored tactical states are not ordinary harmful statuses.

Audit115 Bleed timing specifically remains controlling:

- Bleed deals 2% Max HP when the affected unit successfully acts;
- maximum one Bleed proc per round;
- a lost action does not proc Bleed;
- **any successful HP heal restoring at least 1 HP removes Bleed after that heal resolves**;
- Regen restoring at least 1 HP also removes Bleed.

Therefore any older working-tracker text saying Bleed requires a full heal to clear, or that Split Moment can create two Bleed procs in one round, is superseded.
