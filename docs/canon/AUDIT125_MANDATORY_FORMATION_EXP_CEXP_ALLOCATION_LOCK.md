# 12. Distribution rules

Named/story remainders should be distributed across:
- mandatory named encounters;
- minibosses;
- chapter bosses;
- non-random campaign milestones;
- deterministic chapter/story completion awards.

Do not hold nearly all deterministic EXP/CEXP until a final boss if that breaks intended midpoint progression.

Ordinary random encounter totals remain expectations. Do not add a hidden automatic chapter top-up and do not force extra battles to meet the expected ordinary pool.

Player-EXP lower-level diminishing returns apply to repeatable/ordinary enemy-kill EXP.

This audit does **not** create a parallel CEXP diminishing-return system.
