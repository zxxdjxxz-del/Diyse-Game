# 5. Mastery Point economy — CLOSED

Synthesis is removed.

Each permanent character has exactly:
- 4 Core Masteries;
- 4 Subclass Masteries;
- 8 active Mastery nodes total;
- 8 total automatic Mastery Points.

Exact automatic Mastery Point grants:

1. **Player Lv5**
2. **Player Lv10**
3. **Player Lv15**
4. **Player Lv20**
5. **Sixfold Volition**
6. **Player Lv40**
7. **Player Lv50**
8. **Player Lv60**

No ninth point. No Lv70 surplus point. No Synthesis point.

Unspent Mastery Points may be banked.

Core eligibility remains Base CL3 / 6 / 9 / 12.
Subclass eligibility remains CL3 / 5 / 7 / 11.

Purchase of Subclass Mastery 3 grants donor Relic access when the actual donor Relic has been obtained. Purchase of Subclass Mastery 4 grants donor Legacy access when the actual donor Legacy has been obtained.

The final Lv60 point does **not** define CL13 completion. Class Levels may already be capped. The Lv60 point instead provides the final Mastery-board completion layer shortly before the final locked sequence.

- Ch8 ordinary enemies: Lv32–37

- Ch12: Lv52–57

Optional Elites are normally authored around +1 to +2 levels over surrounding ordinary centers. Mandatory chapter bosses are normally authored around +2 to +3 levels over expected player level entering the boss sequence. These are tuning centers, not formulas.

Regional and Major Hunts remain individually authored above expected player level at unlock and do not dynamically scale.
