# 1. Late-game cap target

Current player-level anchors remain:

- Last Shelter — approximately **Lv60 / 415,400 cumulative EXP**
- normal campaign ending — approximately **Lv62 / 448,100 cumulative EXP**
- level cap — **Lv70 / 594,100 cumulative EXP**

The Last-Shelter Lv60 → Lv70 gap is:

**178,700 EXP**

A broad completionist route should be able to reach Level 70 before Last Shelter without repetitive grinding and without requiring Major Hunt #6.

# 7. Level-70 completionist proof

At Last Shelter:

**415,400 + 195,000 = 610,400 EXP**

**594,100 EXP**

**16,300 EXP**

Therefore:

> **A broad completionist route can reach Level 70 before Last Shelter without requiring Major Hunt #6 or repetitive grinding.**

The buffer is intentional and protects against route variance and some EXP loss after reaching the cap.

---

# 8. Diminishing-return firewall

The lower-level enemy EXP diminishing-return rule applies to repeatable/ordinary enemy-kill EXP.

It does **not** reduce:
- ordinary Side Quest completion EXP;
- Character Quest completion EXP;
- Regional Hunt authored activity-package totals;
- Major Hunt authored activity-package totals;
- mandatory one-time story completion awards.

Controlling philosophy:

> **WEAK ENEMIES DIMINISH — AUTHORED CONTENT DOES NOT**

Optional Hunt-route ordinary enemies may individually yield reduced enemy-kill EXP when outleveled. The deterministic first-clear remainder preserves the Hunt's authored package total.

# 9. Route-profile sanity check

Using the 195,000 authored pre-cutoff pool:

- campaign-only ending: about **Lv62**
- light optional route (~20–30%): about **Lv64–65**
- typical developed route (~40–50%): about **Lv66–67**
- heavy optional route (~60–70%): about **Lv68–69**
- broad completionist: **Lv70 before Last Shelter**

This remains the intended broad progression spread.
