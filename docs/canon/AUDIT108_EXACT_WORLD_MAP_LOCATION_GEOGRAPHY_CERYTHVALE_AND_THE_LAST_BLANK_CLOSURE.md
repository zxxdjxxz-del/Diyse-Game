# 2. Region terminology and map-label rules

The four controlling macro-regional names are:

- **BLACKSTONE** — the Black Host-side region west of the Yahtrean frontier.
- **THE GREYSPIRES** — the northern mountain region; supersedes `Diysereach` and older `Highlands` regional usage.
- **THE WESTWAYS** — western Yahtrea; supersedes `Edgelands`.
- **THE CROWNHOLD** — central/southern royal-core region; supersedes `Southhold`.

### 2.1 Blackstone / Blackspine distinction

- **Blackstone** is the **region**.
- **The Blackspine** is the **mountain range / frontier barrier**.
- `Black Mountains` is deprecated as the formal mountain-range name.
- `The Hostlands` is **not** the formal map-region name. If ever used in prose, it may only function as a broad colloquial/political description of Black Host-controlled lands, not as the formal regional label.

### 2.2 Regional label overlay

The current exact artwork already prints **BLACKSTONE** and **The Blackspine**.

A later non-spatial label pass may add:
- **THE GREYSPIRES**
- **THE WESTWAYS**
- **THE CROWNHOLD**

without moving or altering any geography.

Do **not** add hard regional border lines. Terrain transition should communicate regional change.

### 2.3 Terrain does not override canon region

**Ashfrost Expanse** and **Crownfall Redoubt** remain part of **The Westways** even though their exact-map terrain is mountainous/cold and approaches The Greyspires / Blackspine geography.
