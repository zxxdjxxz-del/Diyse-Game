## 1. Six Faces — Acuity replacement

The formal Six Faces are now:

1. **Might**
2. **Elements**
3. **Grace**
4. **Acuity**
5. **Change**
6. **Ruin**

**Acuity** replaces the former **Resource** Face. The provisional name **Finesse** is not current canon.

Torren is the party's **Face of Acuity** through his Base class **War Archer**.

Acuity's locked conceptual center is:
- perception;
- judgment;
- precision;
- situational awareness;
- timing;
- anticipation;
- route/position assessment;
- rapid decision-making;
- efficient execution;
- speed as a supporting consequence of correct perception and judgment rather than the Face's sole or primary meaning.

Acuity's concise thematic statement is:

> **Acuity turns uncertainty into a path.**

Acuity's universal decision sequence is:

> **See → Decide → Place → Act.**

Acuity rewards better information and correct player judgment rather than omniscience, generic Speed buffs, generic Accuracy buffs, or automated optimal decision-making.

**Face color:** Acuity retains the former fourth Face's **Gold** color unless separately revised later.

There is currently **no dedicated Face symbol/icon system**. Existing scene/production wording should use neutral terms such as **Face markings** or **Face notation** rather than assuming six formal symbols.

Last Cartographer does **not** inherit Last Measure's former maintenance, reserve-management, reactor-allocation, or command-stabilization identity.

- identifies the decisive viable path;

## 3. Acuity Standard Cards — locked set

The four former Resource Standard Cards — **Bastion Reserve, Stormglass Relay, Prismatic Reserve, Lifeward Transfer** — are superseded by the following Acuity set.

### 3.1 Faultline Sight — Perception

**Target:** 1 enemy.

Locked core function:
- reveals currently knowable weaknesses and resistances;
- reveals the next readable/telegraphed action when applicable;
- identifies a tactically relevant exploitable condition or opening;
- does **not** reveal intentionally hidden scripted mechanics that are meant to be discovered through play.

### 3.2 Chosen Course — Judgment

**Target:** 1 ally + 1 enemy.

Locked core function:
- if both have unused pending actions in the current round, moves the selected ally to immediately before the selected enemy;
- creates no extra turn;
- cannot reactivate an ally who already acted;
- cannot be exploited to push an enemy backward indefinitely.

This Card represents the judgment question: **who needs to act before this threat does?**

### 3.3 Predicted Impact — Precision / Anticipation

**Target:** 1 ally.

Locked core function for that ally's next targeted offensive action:
- cannot miss through ordinary accuracy/evasion rules;
- partially bypasses appropriate avoidance defenses;
- gains increased Break/Stagger contribution when correctly exploiting a known vulnerability.

It does not exist merely as a generic raw-damage or guaranteed-critical Card.

### 3.4 Decisive Interval — Timing / Speed

**Target:** 1 enemy.

Locked core function:
- creates an opening lasting until that enemy's next action;
- the first allied offensive action that lands during the opening gains significantly increased Break/Stagger contribution;
- may slightly delay ordinary enemies where legally applicable;
- bosses may resist the delay portion without nullifying the core Break/Stagger benefit;
- expires after one qualifying action.

### Acuity Standard Card acquisition — locked

1. **Faultline Sight** — Hollow Watch Castellan first clear.
2. **Chosen Course** — Deepforge Colossus first clear.
3. **Predicted Impact** — Regional Hunt #9, Mercyfallen Behemoth first clear.
4. **Decisive Interval** — Major Hunt #5, Final Archive Arbiter first clear.

## 4. Acuity optional Prime — Parallax Host

The former Resource optional Prime **Sheltering Host** and its defensive/rescue-network identity are superseded by:

- **Face:** Acuity
- **Optional Prime:** **Parallax Host**

### Core identity

Parallax Host is a coordinated Ancient Diysean manifestation that uses multiple simultaneous viewpoints to eliminate uncertainty, determine exact position/intent, and respond with precision.

Its locked process is:

> **Observe → Compare → Resolve → Strike.**

It is distinct from Last Cartographer:
- **Parallax Host** resolves the present battlefield from multiple viewpoints and acts on that resolved information.
- **Last Cartographer** maps the larger field of possibility and identifies the decisive path.

### Combat identity

Parallax Host emphasizes:
- high Speed and Accuracy;
- anti-Evasion pressure;
- interruption;
- precision against exposed/readable targets;
- coordinated multi-angle attacks;
- lower durability than dedicated defensive optional Primes.

It does **not** cast or duplicate the four Acuity Standard Cards.

### Locked command set

1. **Split Horizon** — multi-target observational assault; reduces Evasion.
2. **Intersecting Lines** — concentrated single-target convergence; improved Break/Stagger effectiveness when target behavior/weakness is known.
3. **Counterposition** — reactive watch; attempts precision interruption against eligible telegraphed actions.
4. **Resolved Position** — higher-state precision strike; ignores ordinary Evasion and gains extra effect against exposed/preparing/readable targets.
5. **Vanishing Point** — Concordant climax; all viewpoints and trajectories converge on one chosen target for a coordinated finishing assault.

Current optional Prime lineup:
- Might — **Oathbound Colossus**
- Elements — **Prismatic Leviathan**
- Grace — **Dawn Shepherd**
- Acuity — **Parallax Host**
- Change — **Living Revision**
- Ruin — **Starfall Engine**

## 11. Final Severance — revised six-Prime sequence

The old Resource-era Final Severance order **Might → Resource → Elements → Change → Grace → Ruin** and Last Measure's reactor-allocation role are superseded.

The locked Final Severance order is:

1. **Last Sentinel — Might: HOLD**  
   Fixes The Last Command's central manifestation in place and prevents withdrawal/shifting of its main continuity.

2. **Last Convergence — Elements: DISTINGUISH**  
   Harmonizes native Crest magic so foreign Entity corruption becomes clearly separable/readable.

3. **Last Cartographer — Acuity: MAP**  
   Constructs a complete live map of every Entity trace, connection, and viable replenishment/reconnection/escape/reconstruction route, then identifies the severance pattern.

4. **Last Sanctuary — Grace: PRESERVE**  
   Defines and protects living people, viable native Crest structure, surviving reactors, and stable systems that must not be severed.

5. **Last Scribe — Change: CONTAIN**  
   Uses Cartographer's map and Sanctuary's protected boundary to rewrite existing Crest geometry around every Entity trace, cutting cross-feed, replenishment, reincorporation, and escape routes so the Entity becomes finite and isolated.

6. **Last Erasure — Ruin: END**  
   Simultaneously destroys every designated Entity trace and remaining means of continuity.

Locked causal shorthand:

> **Hold it → Reveal it → Map it → Protect everything else → Isolate it → Erase it.**

Locked distinction:

> **Last Cartographer determines exactly what must be done; Last Scribe makes the necessary structural change.**

Preserve the already-approved finale architecture around The Reconstituted Entity / The Last Command except where this new six-Prime causality explicitly supersedes the Resource-era operation.
