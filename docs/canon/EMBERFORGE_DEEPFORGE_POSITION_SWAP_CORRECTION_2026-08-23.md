# Emberforge / Deepforge Position Swap Correction — 2026-08-23

**Status:** LOCKED / BOUNDED CORRECTION TO v1.93 / Audit108  
**Scope:** Exact world-map placement for **Emberforge** and **Deepforge** only.

This correction inherits all compatible **v1.93 / Audit108** canon and overrides Audit108's exact-marker placement lock only for the two locations named below.

## Approved change

Swap the map positions/identities of **Emberforge** and **Deepforge** on the current exact world-map authority.

- **Emberforge** moves to the current more southerly Deepforge site.
- **Deepforge** moves to the current farther-north Emberforge site.

All surrounding geography remains unchanged.

Do **not** move or alter:
- Stonewake;
- Frostmere;
- Crownfall Redoubt;
- Ashfrost Expanse;
- roads except where a later explicit road-audit correction is approved;
- rivers;
- mountains;
- terrain;
- any other settlement, landmark, or map marker.

This is a **two-location swap only**, not permission to regenerate or reinterpret the northern map.

## Story/travel effect

The mandatory Chapter 5 route remains:

**Stonewake → Emberforge → Deepforge**

After the swap, the world-map geography now supports that order directly:
- Stonewake lies farther south;
- Emberforge is the next major northern forge/story stop;
- Deepforge is the deeper/farther-north Ancient industrial/maintenance destination and Chapter 5 climax.

The prior workaround in which Deepforge was geographically passed before Emberforge but remained inaccessible is no longer required and should not be treated as canon.

## Chapter 6 compatibility

Frostmere remains fixed. The swap does not change Chapter 6's mandatory start at Frostmere or its local Weather Crown / Crimson Relay geography.

The Deepforge-to-Frostmere transition is now naturally supported by the high Greyspires corridor between the farther-north Deepforge position and Frostmere.

## Change-control rule

Audit108's exact-map lock remains fully active for every other location and geographic feature. Only Emberforge and Deepforge are exempted, and only to perform this exact mutual position swap.
