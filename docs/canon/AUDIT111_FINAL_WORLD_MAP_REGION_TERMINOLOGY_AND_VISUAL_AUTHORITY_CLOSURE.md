## 2. Final region names — LOCKED

The controlling macro-region terminology is now:

- **BLACK HOST TERRITORY** — the Black Host-controlled homeland/territory beyond The Blackspine. This supersedes **Blackstone** as the region/place designation in map labels and prose.
- **THE WESTWAYS** — western Yahtrea.
- **THE GREYSPIRES** — northern Yahtrean mountain region.
- **YAHTRENHOLD** — central/southern royal and historic core region. This supersedes **The Crownhold**.

### Black Host Territory

**Black Host Territory** is a territorial/political control label rather than a conventional country name.

Older references to `Blackstone` should be interpreted as **Black Host Territory** where they refer to the Black Host-controlled homeland/region.

Existing internal place names remain unchanged unless separately revised, including:
- Vorathen
- Vhalmarch
- Draevensreach

### Yahtrenhold

Use the exact spelling **Yahtrenhold**.

- Do not use `The Yahtrenhold` as the formal map label.
- Older `Crownhold` / `The Crownhold` references should be interpreted as **Yahtrenhold** where they refer to this same region.
- Caelora remains the capital; Yahtrenhold is the broader historic royal/core region around it.

**The Blackspine** remains the canonical proper name of the mountain range/frontier barrier between Yahtrea and Black Host Territory.

## 4. Westguard — final name lock

**Westguard** is the controlling proper name of the western settlement/location previously called **Westreach**, and it supersedes the brief interim name **Yahtrens Stand**.

The exact settlement position, terrain, road network, and Crownfall connection remain unchanged.

Older `Westreach` and `Yahtrens Stand` references should be interpreted as **Westguard** where they refer to this same location, pending stale-term cleanup.

The locked logistics relationship is:

**Westguard ↔ Crownfall Redoubt**

The late-war route remains:

**Westguard → Blackspine crossing → Draevensreach → Vhalmarch → Vorathen**
