# Diyse — Quest Combat & Enemy-Reuse Rules
**Historical migration provenance:** v85-era consolidated tracker.
**Authority treatment:** this repository file is current quest-domain authority. Audit/v85 references remain provenance only; exact EXP/CEXP values are owned by `10_PROGRESSION_AND_EXP` and remain provisional pending the planned progression rebuild.
**Historical quest-architecture provenance:** Audit103 plus later accepted quest reductions/corrections.
**Domain rule:** this folder owns optional-activity identity, unlocks, objectives, route/area flow, quest-state outcomes, combat/no-combat classification, completion conditions, and world-state payoff. Exact enemy kits/stats live in `09_ENEMIES_AND_ENCOUNTERS`; exact EXP/CEXP in `10_PROGRESSION_AND_EXP`; item/equipment mechanics in `08_ITEMS_AND_EQUIPMENT`; exact dialogue in `03_DIALOGUE`.


## Ordinary Side Quests
Combat is not mandatory by category.

Valid forms include:
- no combat;
- incidental normal-route combat;
- one or two authored encounters using existing enemies.

No ordinary Side Quest currently has a unique boss.

## Character Quests
Current boss distribution:
- Vaelira — Elemental Forecast Construct
- Cyanis — Crest-Exhausted Warden
- Nimera — **none**
- Seyrik — Black Host Remnant Captain
- Ilyra — **none**
- Torren — Old Relay Warden

No new ordinary enemy family is required for any current Character Quest.

## Reuse
Where optional quests use ordinary enemies:
- preserve the same enemy identity;
- preserve current role/kit/status riders;
- use the appropriate current optional-content numerical package from the enemy/balance authority;
- do not pre-introduce future story enemy families merely to diversify a quest.

## Hunts
Regional and Major Hunts use:
> **fixed authored tuning**

Recommended levels are preparedness guidance, not dynamic scaling formulas.

Do not restore older Party+2 / Party+4 / Party+6 dynamic-Hunt working formulas.

## Cross-domain rule
This folder may name the enemy roster or boss needed by a quest.
It does not duplicate their exact current move tables or raw stats.
