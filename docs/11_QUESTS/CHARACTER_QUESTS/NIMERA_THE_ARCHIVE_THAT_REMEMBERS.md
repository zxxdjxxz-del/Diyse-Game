## Theme
> **Revision is not erasure.**

Nimera confronts the tendency to treat the newest/corrected version as if everything earlier becomes meaningless.

## Archive behavior

- not time travel;
- not a sprawling timeline puzzle;
- not a systems sandbox.

The archive preserves:
- amendments;
- deleted lines;
- abandoned plans;
- changed judgments;
- rejected drafts.

- preserve only the latest valid version;
