- Cyanis Legacy Component

## Grant timing
The item may appear diegetically near the climax, but inventory grant occurs:
> **at quest completion**

Completion therefore:
1. satisfies the authored character-resolution requirement;
2. awards the unique Legacy Component.

No duplicate invisible `resolution item` is required.

## Item nature
Legacy Components are:
- unique;
- non-consumable;
- non-equippable;
- non-sellable;
- not Forge Components;
- not generic crafting materials.

## Finished Legacy boundary
The Character Quest does **not** directly award finished Legacy equipment.

The component is one requirement in that character's secured native Legacy project at Cresthaven.

Full Legacy requirements/traits/stats belong in `08_ITEMS_AND_EQUIPMENT`.
