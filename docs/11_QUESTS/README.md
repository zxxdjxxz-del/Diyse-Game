## Quest-family boundaries
Character Quests:
- exactly one per permanent character;
- runtime remains **provisional/open** and must be set by later research/playtesting;
- optional;
- deepen character/Face/Prime themes without gating main-story comprehension, Story Primes, required Abilities, or the ending;
- award that character's unique Legacy Component at completion.

Ordinary Side Quests:
- grounded world/NPC content;
- ~15–20 minutes;
- may have no combat at all;
- should prefer visible low-cost world-state improvement.

Hunts:
- separate optional combat category;
- not Side Quests;
- not Character Quests;
- enemy mechanics/stats are owned by `09`;
- Prime rewards are owned by `07`;
- EXP is owned by `10`.
