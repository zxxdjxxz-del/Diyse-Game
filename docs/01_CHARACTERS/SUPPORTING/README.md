# Supporting Characters

This folder contains supporting-character biography/personality/relationship authorities.

Two current supporting characters also belong to the exact repository visual-master set:
- `Maevra.md` — **Maevra Solmar**
- `Kessara.md` — **Kessara Durnan**

Their repository filenames remain first-name-only for stable path compatibility; that filename convention does **not** remove their canonical surnames. Their current visual masters are `asset_sources/characters/current/maevra.jpg` and `asset_sources/characters/current/kessara.png`.

For Kessara, restoring the canonical surname **Durnan** does not restore the retired surname-derived workshop label or retired family/workshop branch. Those remain superseded unless explicitly reopened.

Other supporting-character names in this folder—including established royal-family, Edda Harth, and Talia Rell records—remain separate current authorities.

Exact visual authority for Maevra/Kessara lives in `docs/14_ART_AND_VISUALS/PRODUCTION/CHARACTERS/README.md`.
