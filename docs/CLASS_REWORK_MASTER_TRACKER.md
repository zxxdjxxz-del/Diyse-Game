# Diyse — Class Rework Master Tracker

**Status:** ACTIVE WORKING DESIGN TRACKER — NOT YET MASTER-CANON PROMOTION  
**Parent authority:** v1.84 / Audit99 plus all compatible inherited class/equipment canon and newer explicit user corrections.  
**Purpose:** Consolidate the current Base-class and Subclass redesign so the reciprocal-training architecture, CL13 progression, equipment unlocks, and revised class kits stay synchronized.

---

## 1. Core class architecture — current working direction

### Class level caps

- **Base Class cap: CL13** — current approved working direction.
- **Subclass cap: CL13** — current approved working direction.
- Base and Subclass Class EXP remain separate from character level.
- Class EXP goes only to the currently equipped class unless explicitly changed later.
- The system should be tuned so class growth continues meaningfully through approximately character Level 55 rather than finishing too early.

### Sixfold Accord

- No Subclass before the Sixfold Accord.
- After the Accord, each permanent character learns from one reciprocal training partner.
- Subclass names are **not** constraints on donor selection and may be renamed after mechanics are settled.

### Reciprocal training pairs

- **Cyanis ⇄ Vaelira**
- **Ilyra ⇄ Seyrik**
- **Torren ⇄ Nimera**

The training relationship is reciprocal rather than a one-way donor ring.

---

## 2. Equipment persistence

- Permanent equipment slots remain exactly **Weapon / Secondary / Armor**.
- Once equipment access is legally learned, it remains usable regardless of currently selected Subclass under the existing open-equipment rule.
- A two-slot weapon/Conduit occupies Weapon + Secondary.
- Donor equipment is **not cherry-picked**. The recipient ultimately learns the donor Base tradition's complete legal ordinary equipment package and its native advanced equipment permission.

---

## 3. Base-class CL13 structure

Existing Base kits have **six normal Base abilities** and should remain six-ability kits unless a separate kit audit explicitly changes an individual class.

Current working progression skeleton:

| Base CL | Major unlock |
|---|---|
| **CL1** | Trait Rank I + early Base abilities / starting equipment |
| **CL2** | normal class growth |
| **CL3** | normal class growth / ability timing to be reconciled per existing kit |
| **CL4** | normal class growth / ability timing to be reconciled per existing kit |
| **CL5** | **native advanced equipment permission** |
| **CL6** | Trait Rank II |
| **CL7** | later Base ability progression |
| **CL8** | normal class growth |
| **CL9** | later Base ability progression |
| **CL10** | later Base ability progression |
| **CL11** | late Base ability progression if needed by kit reconciliation |
| **CL12** | Trait Rank III |
| **CL13** | Base Ultimate |

Exact placement of all six Base abilities still needs a six-class reconciliation pass. Do not delete an existing Base ability merely to force a generic level table.

### Base CL5 rule

**CL5 is a native equipment breakthrough inside the character's own Base tradition.**

It should change legal equipment use/configuration rather than be a generic stat bump whenever the tradition has a meaningful equipment breakthrough available.

Current approved/working examples:

- **Cyanis / Crest Knight:** CL5 unlocks use of a **second Sword in Secondary**, enabling dual-Sword loadouts.
- **Ilyra / Blue Warden:** CL5 unlocks **Shield access**. Her Base Primary is **Wardrod**; Blue Warden Secondary is **Shield or Focus** once the Shield permission is learned.
- **Nimera / Cardweaver:** CL5 unlocks **two-handed Conduits** in addition to one-slot Conduits.
- **Vaelira / Green Arcanist:** **Focus access** is the leading CL5 candidate; Vaelira joins after this milestone and would arrive with it already learned if retained.
- **Torren / War Archer:** CL5 native breakthrough remains unresolved. Torren's Base weapon family is specifically **Great Bows**, and Great Bows already require both Weapon + Secondary; do not invent a generic Secondary for him.
- **Seyrik / Ruin Vanguard:** CL5 native breakthrough remains unresolved. His Base weapon family is **Two-Handed Swords**, which already occupy Weapon + Secondary; do not invent a generic Secondary for him.

### Recruitment and Base CL

Late recruits do **not** begin Base CL1 by default. Their starting Base CL should reflect their established training and campaign timing.

Current recruitment chronology to respect:

- Cyanis — Chapter 0
- Ilyra — Chapter 0
- Torren — Chapter 1
- Nimera — Chapter 3
- Vaelira — Chapter 4
- Seyrik — Chapter 6

Vaelira and Seyrik are expected to join **above Base CL5**. Their CL5 native breakthroughs are therefore pre-recruitment mastery rather than player-witnessed unlocks. Nimera may join around the CL5 neighborhood; exact starting CLs wait for the new CEXP curve.

## 4. Subclass CL13 structure

Subclasses now use **five normal Subclass abilities**, a three-rank Trait, and an Ultimate.

Current working progression:

| Subclass CL | Major unlock |
|---|---|
| **CL1** | donor basic Primary access + Trait Rank I + Ability 1 |
| **CL2** | normal class growth |
| **CL3** | donor Armor access |
| **CL4** | Ability 2 |
| **CL5** | donor **native advanced equipment permission** / Secondary package where applicable |
| **CL6** | Trait Rank II |
| **CL7** | Ability 3 |
| **CL8** | normal class growth |
| **CL9** | Ability 4 |
| **CL10** | normal class growth |
| **CL11** | Ability 5 |
| **CL12** | Trait Rank III |
| **CL13** | Ultimate |

### Meaning of Subclass CL5

Subclass CL5 should mirror the donor tradition's own Base CL5 equipment breakthrough rather than always meaning "Secondary."

Examples:

- Vaelira learning Cyanis: CL5 eventually includes Cyanis's **dual-Sword permission**.
- Seyrik learning Ilyra: CL5 includes Ilyra's advanced **Shield permission** and the full legal Blue Warden Secondary package.
- Torren learning Nimera: CL5 includes **two-handed Conduit permission** plus the donor's legal Secondary access where applicable.

This allows traditions with no separate Secondary to remain coherent without artificial exceptions.

## 7. Hunter's Measure — Torren ⇄ Nimera shared language

Hunter's Measure is now the leading shared War Archer-derived tactical state for this reciprocal pair.

- Torren remains the original expert.
- Nimera's Torren-derived Subclass can also **apply Hunter's Measure**.
- Torren and Nimera can exploit Hunter's Measure applied by the other.
- Do not create a redundant Nimera-only mark unless a later problem requires it.

Keep distinct:

- **Hunter's Measure** — War Archer quarry/target state.
- **Diysean Appraisal** — Nimera Base information reveal; does **not** create an "Appraised" status.

## 8. Nimera — Torren-derived Archer Subclass

**Status:** ACTIVE PROVISIONAL DESIGN.  
**Old direction being replaced:** Cyanis-derived / Sixfold Knight framing.

### Design goal

Nimera genuinely learns Torren's War Archer discipline: target assessment, Hunter's Measure, prepared interruption, pinning/control, penetration against hard targets, repeated/multihit pressure, and practical exploitation of known prey. Nimera expresses those lessons through her analytical/evidence-driven personality.

The Subclass should be **less Face-based** than the retired Sixfold Knight direction. Face/Card complexity remains primarily in Cardweaver.

### Current five-ability spine

**CL1 — Measured Shot** *(working name)*
- Bow attack.
- Applies **Hunter's Measure**.
- May receive an accuracy/quality bonus when Diysean Appraisal has already revealed the target.
- Does not create an Appraised state.

**CL4 — Held Argument** *(working name)*
- Prepared bow response descended from Torren's Watchful Aim concept.
- Fires when the chosen enemy begins an eligible Interruptible action.
- Stronger/more reliable against Hunter's Measure.

**CL7 — Pin the Variable** *(working name)*
- Bow control attack descended from Torren's pinning technique.
- Applies Speed Down or equivalent mobility/control pressure.
- Hunter's Measure improves reliability and/or penetration.

**CL9 — Structural Failure** *(working name)*
- Heavy single-target Physical bow attack.
- Significant Defense penetration.
- Strong against armored/high-Defense enemies, targetable components, devices, wards, and similar structural targets.
- Hunter's Measure adds a payoff.

**CL11 — Corroboration** *(working name)*
- Controlled multihit/repeated-shot technique.
- Later hits become more accurate and/or gain Critical Chance against Hunter's Measure.
- Intended to represent Torren's sustained shooting translated through Nimera's evidence/proof personality.

### Trait — Applied Evidence *(working name)*

- **Rank I / CL1:** improved Base Hit against Hunter's Measure.
- **Rank II / CL6:** Subclass attacks additionally gain Critical Chance against Hunter's Measure.
- **Rank III / CL12:** Subclass attacks additionally gain modest Defense penetration against Hunter's Measure.

No personal gauge and no new mark.

### Ultimate — Final Annotation *(working name)*

**CL13.**

- Massive single-target Physical bow attack.
- Very high Defense penetration and high Base Hit.
- Especially effective against large targets, Hunts, armored enemies, components, devices, wards, and other hard points.
- Major payoff against Hunter's Measure.
- Current preference: does **not** consume Hunter's Measure, preserving Torren/Nimera cross-synergy.

### Provisional selected-Subclass stat package

Not yet locked:

- Attack +8%
- Accuracy +8%
- Speed +6%
- Defense −6%

### Name status

No final name locked. Previous working ideas such as Proof Archer / Pattern Archer / Threadshot remain non-canon placeholders only.
