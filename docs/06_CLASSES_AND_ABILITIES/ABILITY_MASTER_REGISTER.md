# Diyse — Ability Master Register

**Status:** REBUILD REGISTER  
**Authority:** `CLASS_SYSTEM_MASTER.md` and `ABILITY_RULES.md`.

The previous exact Ability-name/MP/unlock table is not current combat authority.

## Current structural requirement

Each rebuilt class must ultimately satisfy:

- Base Class: **6–8 active Abilities**
- Subclass: **4–6 active Abilities**
- combined mature native toolkit: roughly **10–14 active Abilities**

Starting characters begin with **3 Base active Abilities**.

When Subclass access is gained, it immediately grants **2 Subclass active Abilities**.

## Registration requirement

A rebuilt active Ability is not current until its owning class file defines all required current fields:

- MP Cost
- Execution
- Return
- Targeting
- Potency or fixed magnitude
- output type
- element where relevant
- crit eligibility
- Interruptible / Delay-only / Uninterruptible classification
- status chance where relevant
- timeline effect where relevant
- explicit conditions/special rules

Exact names, counts within the allowed bands, MP costs, and CL unlock points remain open until that class is rebuilt.
