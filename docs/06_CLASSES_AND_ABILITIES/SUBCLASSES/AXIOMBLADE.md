## Trait ranks
- Rank I: dealing a standard element stores it through end next round; next Neutral damaging Axiomblade Ability adopts and consumes the stored element; new store replaces old; multielement action does not establish a store.
- Rank II: consuming stored element grants +10% final damage.
- Rank III: consumption also grants +15% applicable penetration on both Hybrid axes.
