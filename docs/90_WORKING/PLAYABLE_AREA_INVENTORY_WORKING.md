# Diyse — Playable Area Inventory

**Status:** CURRENT WORKING INVENTORY / PHASE A COMPLETE ENOUGH TO BEGIN MAPPING

**Purpose:** identify every currently known gameplay-relevant base map, route packet, facility, optional branch and stateful reuse that must eventually receive a build-ready layout blueprint.

This inventory is derived from current story, world/travel, quest and Hunt authority. It does **not** replace those owners. It translates them into level-design production units.

## Layout maturity legend

- **L0 — location only:** place exists in canon, but even local traversal sequence is not yet sufficiently defined.
- **L1 — sequence known:** macro/local order and function are known, but no exact playable geometry/blockout is approved.
- **L2 — reuse/state variant:** should reuse an existing base map/route with quest/story-state changes; do not build a duplicate map.
- **L3 — blueprint locked:** exact playable topology/blockout approved and ready for environment construction.

Current audit result:
> **No repo document currently establishes an L3 build-ready playable topology for the production areas below.**

The world map is spatially locked at macro scale. That does **not** make individual field/town/dungeon layouts L3.

# I. Mapping Priority

## Priority A — establish the layout language
Map three representative packets before mass production:

1. **Outdoor route:** Chapter 0 Convoy Road → Wreck Field, or Chapter 10 Eastern Old Road.
2. **Settlement/hub slice:** Greenhollow or Cresthaven.
3. **Dungeon/facility slice:** Reaction Annex or Poisoned Waterworks/Sunken Archive.

These three should establish:
- world-unit scale;
- camera angle/distance;
- path width;
- party/enemy encounter footprint;
- landmark density;
- elevation grammar;
- transition/loading conventions;
- average route length;
- HD-2D foreground/midground/background layering.

## Priority B — map Chapter 0 end to end
Once the scale standard is accepted, map the entire Chapter-0 route as the first complete production-level route packet.

Why Chapter 0 is useful:
- compact;
- includes outdoor road, battlefield, survivor-routing space, camp and hub handoff;
- exercises combat and non-combat spaces;
- exposes camera/scale/readability problems early;
- does not require a huge settlement or dungeon to validate the pipeline.

## Priority C — proceed chapter-by-chapter while sharing reusable bases
After Chapter 0, build the base-map/route blueprint library in story order while avoiding duplicate work for persistent hubs and optional-content state variants.

# J. AI Environment Handoff Rule

No environment AI receives only a prose prompt such as “make a fantasy forest route.”

The minimum handoff for a production area is:
1. approved topology/blockout;
2. exact entrances/exits;
3. mandatory story landmarks;
4. combat/no-combat zones;
5. elevation and camera intent;
6. reuse/state-change requirements;
7. approved Diyse visual benchmark references;
8. negative constraints and forbidden geography changes;
9. engine/export requirements.

The external AI may solve **construction and visual execution**. It may not silently redesign canon topology.
