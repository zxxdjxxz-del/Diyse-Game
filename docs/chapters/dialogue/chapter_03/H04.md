## H04_B001

Cresthaven Common room at dinner. A protected case containing the static Ruby Last Sentinel Card occupies one chair beside the table because no one has decided where the case should go during meal setup. Maevra is present in the hub and joins late enough to be logistically valid.

**TORREN:** Move it.

**NIMERA:** Where?

**TORREN:** Not the chair.

**CYANIS:** He isn't eating.

Everyone looks at Cyanis.

**CYANIS:** It. It isn't eating.

**NIMERA:** Good recovery.

**CYANIS:** Thank you.

## H04_B002

**ILYRA:** Someone needs the chair.

**NIMERA:** I know.

**ILYRA:** Then move the case.

**NIMERA:** I'm deciding where it wants—

Nimera stops herself.

**NIMERA:** Where it should go. If “want” applies at all, which it does not, because I am not doing this.

**CYANIS:** Doing what?

**NIMERA:** What you just did.

**CYANIS:** I corrected myself.

**NIMERA:** So did I.

## H04_B004

Ilyra simply stands, lifts the protected case using the approved handling grips, and moves it onto a side cabinet within sight but off the chair.

## H04_B005

**CYANIS:** So Last Sentinel is not invited to dinner.

**NIMERA:** It didn't have a name before.

**ILYRA:** Neither did the chair.

**NIMERA:** The chair still doesn't.

**CYANIS:** Give it time.
