# Diyse — Kessara Relic Copy Rules

**Status:** ACTIVE RELIC AUTHORITY  
**Authority:** current items/equipment-domain owner plus later explicit approved corrections.  


## Closed core mechanic

To forge the one allowed duplicate of a Relic:

1. the original Relic must already have been obtained;
2. one matching Face **Relic-copy-specific Forge Component** is required;
3. the resulting copy is mechanically identical to the original.

Maximum:
> **2 copies total per Relic identity**
- 1 original
- 1 forged duplicate

No Forge Component can create a third copy.

## Legacy firewall
Legacies cannot be copied.

Legacy-gate components:
- advance the native Legacy project;
- do not duplicate Legacy equipment.

## Donor access
Donor Relic access never creates a Relic copy.
A receiver equips the actual original/copy inventory instance that exists.
