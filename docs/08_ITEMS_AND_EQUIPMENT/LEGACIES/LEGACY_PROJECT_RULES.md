# Diyse — Native Legacy Project Rules

**Status:** ACTIVE LEGACY AUTHORITY  
**Authority:** current items/equipment-domain owner plus later explicit approved corrections.  


There are exactly **17 native Legacy equipment pieces** across six character packages.

## Native Legacy completion requirements

A native Legacy project requires the established combination of:
1. native Base Class completion at **CL13**;
2. all four native Core Masteries;
3. the character's Character Quest / authored personal resolution;
4. that Character Quest's unique Legacy Component;
5. the Face-linked Legacy precursor;
6. **Legacy Gate A** Face material;
7. **Legacy Gate B** Face material;
8. Kessara project availability.

## Gate release structure
- **Gate A** releases the package's weapon.
- **Gate B** releases the remaining pieces in the package.

This prevents Ilyra's four-piece package from requiring four separate scarce Face gates.

## Native versus donor Legacy
The character's own native Legacy does **not** require:
- Synthesis;
- donor Legacy Mastery;
- a duplicate/shared Legacy artifact.

Donor access:
- receiver reaches current Subclass CL11 Legacy Mastery;
- actual donor Legacy item must already exist;
- receiver equips that same inventory item.

## Unique
Legacies cannot be copied.

## Power hierarchy
> Ordinary < Relic < Legacy

Relics retain specialist niches, but the Legacy package is stronger overall.
