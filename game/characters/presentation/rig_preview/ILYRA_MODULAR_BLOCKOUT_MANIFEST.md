# Ilyra Modular UAL Blockout — Fidelity Manifest

Status: PROTOTYPE / NON-CANON 3D BUILD

Purpose: determine whether Diyse's approved Ilyra silhouette and equipment language can sit convincingly on the Universal Animation Library skeleton before a production mesh is modeled and skinned.

## Authority boundary

The latest approved Ilyra B00 image is authoritative. The blockout may approximate only broad construction and motion behavior. It cannot redefine her face, anatomy, costume, colors, equipment, or proportions.

## Preserved UAL foundation

- Exact 65-bone UAL core skeleton
- Existing skin weights and joint assignments on `Ilyra_AnimeBody_UAL.glb`
- UAL1 and UAL2 non-root-motion animation libraries
- No new core deformation bones introduced in this pass

## Controls

- `SPACE` — next animation
- `P` — pause/resume
- `V` — toggle the new B00-guided detail layers for comparison
- `Q / E` — rotate character in 15-degree steps
- `R` — restart sequence
- `ESC` — quit preview

## Production conversion still required

A final Ilyra asset still needs purpose-built topology, UVs, textures/material masks, exact anime face modeling, production hair geometry, exact B00 clothing cuts, weighted cloth/hair secondary bones or physics, final Wardrod/shield models, LODs, collision setup, and engine import validation.
