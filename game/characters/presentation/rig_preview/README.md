# Diyse UAL / Ilyra Rig Preview

This folder records the staged proof path from the stock Universal Animation Library mannequin to the first actual Ilyra replacement-mesh deformation test.

## Required UAL binaries

Place the supplied non-root-motion UAL assets in:

`asset_sources/animation/ual/`

- `Mannequin_F.glb`
- `UAL1_Standard.glb`
- `UAL2_Standard.glb`

The older proof scenes use `Ilyra_AnimeBody_UAL.glb` when generated by `tools/animation/generate_ilyra_anime_body_proxy.py`.

The current replacement-mesh preview additionally expects:

- `Ilyra_ProductionMesh_v06_UAL_SpringReady.glb`

Binary character/UAL assets are not committed through the text-oriented repository connector.

## Regression stages

### 1 — stock UAL mannequin

`ual_rig_preview.tscn`

Proves UAL1 + UAL2 animation-library merging on the female UAL skeleton.

### 2 — Ilyra motion proxy

`ilyra_ual_proxy.tscn`

Adds abstract palette, hair, cape and utility cues to the stock mannequin. Motion proof only.

### 3 — reshaped anime-body proof

`ilyra_anime_body_ual.tscn`

Uses conservative surface-only proportion edits while preserving the UAL skeleton, joints, weights and inverse-bind data. Adds Wardrod/shield proxies.

### 4 — modular blockout

`ilyra_modular_blockout.tscn`

Adds B00-guided character construction cues and comparison controls.

### 5 — authored geometry

`ilyra_authored_geometry.tscn`

Replaces the most obvious primitive proxy pieces with generated custom triangle geometry. Retained as the rigid-attachment comparison baseline.

### 6 — deformation-aware weighting

`ilyra_deformation_aware.tscn`

Introduces true multi-bone skinning for torso cloth, hair, cape and tabards while keeping hard equipment rigid.

### 7 — production-topology transition

`ilyra_production_topology.tscn`

Tests broader continuous garment surfaces, shoulder/clavicle weighting, hip/thigh transitions, sleeves, hair mass and cape-root weighting.

### 8 — spring secondary-motion proof

`ilyra_secondary_motion.tscn`

Appends 35 auxiliary bones after the unchanged 65-bone UAL core and proves the intended Godot `SpringBoneSimulator3D` architecture:

- five 4-bone hair chains
- three 5-bone cape chains
- head / upper-torso / hip collisions
- optional wind

Stage 8 still uses proof geometry for the spring-driven hair/cape.

## Current active test — Ilyra Production Mesh v0.6

Run:

`ilyra_production_v06_preview.tscn`

This is the first preview that moves beyond the mannequin/proxy visual shell and uses the actual replacement-mesh candidate.

### v0.6 architecture

- original 65 UAL joints remain first and unchanged
- 35 auxiliary spring bones are appended after them
- 100 skin joints total
- the **actual five long-hair volumes** from the replacement model are weighted to the five hair spring chains
- the **actual pale-blue cape mesh** is bilinearly weighted across three cape spring chains
- no duplicate Stage 8 ribbon/cape proxy is generated
- face, bangs, clothing, Wardrod, shield and body deformation continue to use only UAL joint slots 0–64
- covered mannequin-derived torso/limb understructure has been pruned to reduce skin breakthrough in extreme poses

### v0.6 stress loop

T-pose → Walk → Jog → Sprint → Crouch → Jump Start → Jump Land → Roll → Shield Dash → Warden Cast → Knockback.

### v0.6 controls

- `SPACE` next animation
- `P` pause/resume
- `M` springs on/off
- `F` mild wind on/off
- `N` spring-bone markers
- `Q / E` rotate manually
- `T` automatic turntable
- `R` restart sequence
- `ESC` quit

See `ILYRA_PRODUCTION_V06_LIVE_MANIFEST.md` for the current known deformation/modeling issues and the exact production boundary.

## Direction from here

Do **not** add another abstract rig stage by default. The UAL core, multi-bone deformation path and spring architecture are sufficiently proven for continued character production.

Next passes should respond to concrete failures seen on the actual v0.6 replacement mesh: face likeness, hair topology, ankle/boot transitions, shoulder/elbow/hip weights, hard-gear intersections, cape/hair spring tuning, UVs and final materials.

## Authority boundary

None of these 3D proof meshes are Ilyra visual canon. The approved cleaned B00 remains exact authority for her face, vivid jade eyes, windswept blonde hair, slightly athletic natural-waist proportions, fitted white/pale-blue Warden clothing, restrained decoration, brown utility gear, light silver guards, pale-blue cape, colors, silhouette, Wardrod and shield design.

The UAL animation foundation is implementation infrastructure; it must not override the approved B00 visual identity.
