# Diyse UAL / Ilyra Rig Preview

This folder records the staged proof path from the stock Universal Animation Library mannequin to the current Ilyra replacement-mesh deformation test.

## Required UAL binaries

Place the supplied non-root-motion UAL assets in:

`asset_sources/animation/ual/`

- `Mannequin_F.glb`
- `UAL1_Standard.glb`
- `UAL2_Standard.glb`

Older proof scenes also use `Ilyra_AnimeBody_UAL.glb` when generated by `tools/animation/generate_ilyra_anime_body_proxy.py`.

The current replacement-mesh preview additionally expects:

- `Ilyra_ProductionMesh_v07_UAL_SpringReady.glb`

Binary character/UAL assets are not committed through the text-oriented repository connector.

## Regression stages

### 1 — stock UAL mannequin
`ual_rig_preview.tscn`

Proves UAL1 + UAL2 animation-library merging on the female UAL skeleton.

### 2 — Ilyra motion proxy
`ilyra_ual_proxy.tscn`

Adds abstract Ilyra palette/silhouette cues to the stock mannequin.

### 3 — reshaped anime-body proof
`ilyra_anime_body_ual.tscn`

Conservative surface-only proportion edits while preserving the UAL skeleton, joints, weights and inverse-bind data.

### 4 — modular blockout
`ilyra_modular_blockout.tscn`

Adds B00-guided construction cues and comparison controls.

### 5 — authored geometry
`ilyra_authored_geometry.tscn`

Generated custom triangle geometry; retained as the rigid-attachment comparison baseline.

### 6 — deformation-aware weighting
`ilyra_deformation_aware.tscn`

True multi-bone skinning for torso cloth, hair, cape and tabards while hard equipment remains rigid.

### 7 — production-topology transition
`ilyra_production_topology.tscn`

Tests broader continuous garment surfaces, shoulder/clavicle weighting, hip/thigh transitions, sleeves, hair mass and cape-root weighting.

### 8 — spring secondary-motion proof
`ilyra_secondary_motion.tscn`

Appends 35 auxiliary bones after the unchanged 65-bone UAL core and proves the intended Godot `SpringBoneSimulator3D` architecture: five 4-bone hair chains, three 5-bone cape chains, collision proxies and optional wind.

## Replacement-mesh regression — v0.6

`ilyra_production_v06_preview.tscn`

First live scene using the actual replacement Ilyra shell rather than the older mannequin/proxy visual construction. v0.6 directly spring-weights the real five long-hair volumes and real pale-blue cape, prunes covered mannequin understructure, and keeps the original 65 UAL joints first in the skin.

v0.6 exposed large flexible-to-rigid seam gaps at the wrists and ankles, so it is retained as the regression point for that failure.

## Current active test — Ilyra Production Mesh v0.7

> **Current-master mismatch warning:** v0.7 proves deformation architecture, not current appearance fidelity. Its long-hair replacement geometry predates the latest exact Ilyra source and must not be carried forward as the final hair silhouette.

Run:

`ilyra_production_v07_preview.tscn`

v0.7 keeps the complete v0.6 UAL + spring architecture and adds flexible connector geometry across the missing deformation spans:

- `lowerarm → hand` underlayers beneath bracer/glove
- `calf → foot` underlayers beneath greave/boot

Measured animated seam gaps improved from roughly **0.21–0.40 m** in v0.6 to roughly **0.01–0.025 m** in v0.7 across Walk, Crouch and Roll.

### v0.7 architecture

- original 65 UAL joints remain first and unchanged
- 35 auxiliary spring bones remain appended after them
- 100 skin joints total
- five long-hair prototype volumes are spring-weighted **for deformation proof only; this geometry is not current visual authority**
- actual pale-blue cape is spring-weighted across three chains
- no duplicate Stage 8 proxy hair/cape
- face, bangs, clothing, Wardrod, shield and connector deformation use only the intended core or auxiliary joint ranges
- covered mannequin-derived torso/limb understructure remains pruned

### v0.7 stress loop

T-pose → Walk → Jog → Sprint → Crouch → Jump Start → Jump Land → Roll → Shield Dash → Warden Cast → Knockback.

### controls

- `SPACE` next animation
- `P` pause/resume
- `M` springs on/off
- `F` mild wind on/off
- `N` spring-bone markers
- `Q / E` rotate manually
- `T` automatic turntable
- `R` restart sequence
- `ESC` quit

See `ILYRA_PRODUCTION_V07_LIVE_MANIFEST.md` for the seam-repair details and current production boundary.

## Direction from here

Do **not** add another abstract rig stage by default. The UAL core, multi-bone deformation path and spring architecture are sufficiently proven.

Next passes should respond to visible failures on the actual v0.7 model while rematching the current exact Ilyra master: exact face likeness, replacement of the old long-hair prototype with the current **neatly tied-back shorter blonde-hair silhouette**, boot/glove/guard modeling, shoulder/elbow/hip weighting, tabard/hard-gear intersections in extreme poses, spring tuning, UVs and final materials.

## Authority boundary

None of these 3D proof meshes are Ilyra visual canon.

Current exact appearance authority:
> `asset_sources/characters/current/ilyra.jpg`

with the matching lock:
> `docs/14_ART_AND_VISUALS/PRODUCTION/CHARACTERS/ILYRA_CURRENT_VISUAL_LOCK.md`

That exact source controls Ilyra's face, hair, body proportions, clothing, armor/guards, colors, silhouette, Wardrod/shield presentation and incidental visual detail. Current runtime shorthand requires the **neatly tied-back shorter blonde-hair silhouette**, not the older long-hair proof geometry.

The UAL animation foundation and all intermediate meshes are implementation infrastructure; they must not override the exact approved visual identity.
