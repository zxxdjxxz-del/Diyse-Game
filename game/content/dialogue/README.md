**Live runtime authority:** `game/content/dialogue/current/`

`current/` is generated from the approved standalone dialogue atomics under `docs/03_DIALOGUE/PRODUCTION/` and is the only chapter-dialogue tree runtime/game code should consume.

`proof/` contains explicit proof/test fixtures only. It is not story or wording authority.

Chapter 4 currently has **no approved current runtime dialogue resources**. Its B01-B12 presentation layer is structural/pre-dialogue only until exact Chapter-4 dialogue passes the production approval gate.
