# Diyse UI Portrait Derivatives

Approved menu/status/party portrait derivatives belong here after they are derived from and reviewed against the current character masters in `../../current/`.

## Purpose

These assets prioritize immediate character recognition at UI scale while remaining subordinate to the exact current master.

Preserve:
- facial identity and age read;
- eye color;
- hair silhouette;
- dominant costume/palette read;
- enough signature armor/equipment/ornament to identify the character correctly.

Simplify only detail that cannot survive the actual UI scale. Do not redesign a character to make a frame easier to fill.

## Output specification

Exact crop, pixel dimensions, frame shape and background treatment remain downstream of the approved menu/status/party UI layout. Do not lock arbitrary dimensions in this source lane.

When exports are approved, record:
- stable character ID;
- UI variant/purpose;
- source master path/fingerprint;
- output dimensions;
- crop/framing;
- transparency/background treatment;
- approval status.

Do not place current B00 master images here as copies. This lane contains derivatives only.
