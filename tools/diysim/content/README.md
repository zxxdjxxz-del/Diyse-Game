# Combat Content Sections

Reusable authored combat content is separated by family. Do not mix guests with permanent characters, bosses with ordinary enemies, or Hunts with story bosses.

Sections:
- `characters/`
- `guests/`
- `ordinary_enemies/`
- `elites/`
- `story_bosses/`
- `regional_hunts/`
- `major_hunts/`
- `support_objects/`

Definitions here should point back to their current owning canon source and should not contain experimental balance overrides.
