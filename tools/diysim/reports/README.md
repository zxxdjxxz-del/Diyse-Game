# Simulation Reports

Owns generated/recorded outputs and certification comparisons.

Report families should remain separate as coverage grows:
- regression reports;
- mandatory-vs-completionist comparisons;
- chapter route/attrition reports;
- story boss reports;
- Elite reports;
- Regional Hunt reports;
- Major Hunt reports;
- global sensitivity comparisons;
- Prime/Card/resource-economy regressions.

Every report should record the source commit, scenario, run count, seed policy, owner data version, applied overlays, and key metrics. Reports are evidence, not rule authority.
