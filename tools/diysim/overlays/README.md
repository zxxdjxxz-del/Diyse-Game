# Balance Overlays

Owns non-destructive balance experiments and sensitivity layers.

Examples:
- global enemy direct-damage Power ×1.20;
- boss +5 effective core-stat levels with displayed level/HP unchanged;
- HP/ATK/DEF/Spirit/Speed sweeps;
- boss-local action-density candidates;
- targeted Power/mechanic variants.

Rules:
- every overlay must be labeled experimental/working until approved;
- overlays compose on top of current owner data;
- overlays never rewrite canonical content definitions;
- reports must state exactly which overlays were applied;
- an approved result is promoted through the owning canon workflow, not by silently making an overlay the default.
